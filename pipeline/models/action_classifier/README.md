# Action Classifier Model (SGIE)

Secondary GIE for WasteWatch — classifies actions on person/vehicle crops from the primary RF-DETR detector.

## Architecture

MobileNet-V2 with 8-class output head, optimized for TensorRT FP16 inference.

## Action Classes

| ID | Label | Threat Level |
|----|-------|-------------|
| 0 | dumping_waste | critical |
| 1 | carrying_object | warning |
| 2 | loading_unloading | warning |
| 3 | standing_idle | low |
| 4 | walking | none |
| 5 | running | low |
| 6 | driving | none |
| 7 | normal_activity | none |

## Training Data Requirements

Fine-tune on a dataset with the 8 action categories above. Recommended sources:

- Custom annotated footage from WasteWatch cameras (priority)
- UCF101 / Kinetics subsets for general action priors
- Synthetic augmentation of dumping/carrying scenarios

Input: 224x224 RGB crops of person/vehicle bounding boxes.

## Export and Build

```bash
# 1. Export ONNX (with ImageNet backbone, replace weights after fine-tuning)
python scripts/export_action_classifier_onnx.py

# 2. Build TensorRT FP16 engine
bash scripts/build_action_engine.sh
```

## Expected Performance

- ~50ms per batch of 16 crops at FP16 on Jetson Orin / RTX GPUs
- Runs every 3rd frame (interval=3 in SGIE config) for ~10 FPS effective rate
- Enables sub-second alerting for dumping_waste detections (vs. 25s with dwell-only)

## Files

- `action_classifier.onnx` — ONNX model (generated by export script)
- `action_classifier_fp16.engine` — TensorRT engine (generated by build script)
